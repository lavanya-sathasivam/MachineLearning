# Telecom Customer Churn Prediction

Predict whether the customer exited or not in a telecom company using Logistic Regression based on features like:

- Gender
- Senior Citizen
- Having Partner
- Dependents
- Tenure
- Having phone and internet service
- and more..

Steps:
- Analysed the dataset
- Preproecessed them using seaborn, pandas, numpy 
- Visualized for better understanding
- Practiced Feature Scaling
- Used Logistic Regression model and compared the results with different test size and random_state

Accuracies
- 81.48
