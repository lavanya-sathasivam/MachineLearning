# Regression models

Predict the price of a car using Linear and Ridge Regression based on features like:

- Car Model
- Engine Power
- Previous Owners
- Age in Days
- Number of kilometers


Steps:
- Analysed the dataset
- Preproecessed them using seaborn, pandas, numpy 
- Visualized for better understanding
- Practiced Feature Scaling
- Used both models and compared the results with different test size and random_state

Accuracies
- Linear Regression - 84.26
- Ridge Regression - 84.27
