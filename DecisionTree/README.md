# Titanic Classification 

Predict whether the passenger survived or not from the Titanic using Logistic Regression based on features like:

- Passenger Class
- Gender
- Age
- Siblings Count
- Parent Children
- Cabin
- Embarked

Steps:
- Analysed the dataset
- Preproecessed them using seaborn, pandas, numpy 
- Removed outliers using various methods
- Visualized for better understanding
- Practiced Feature Scaling
- Used Decision Tree model and compared the results with different test size and random_state

Accuracy
- 77.23
